# BYTE

BYTE is my own music player and server monitoring dashboard, hosted on my homelab and designed around a repurposed Amazon Fire HD 6 tablet.

## Project scope
- Spotify integration and music interface
- Server monitoring dashboard
- Minimalist near-black interface with crimson accents
- Android/ADB experimentation and self-hosted backend

## Learning
Building BYTE has involved API integration, application deployment, debugging and designing for older hardware.
