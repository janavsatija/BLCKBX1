# Inspiration and references

- [Jim's Garage](https://github.com/JamesTurland/JimsGarage): reusable Compose deployments, automation and Ansible/Kubernetes examples.
- [Khue's Homelab](https://github.com/khuedoan/homelab): Glance dashboard, GitOps, infrastructure as code and documentation.
- [Homelable](https://github.com/Pouzor/homelable): interactive network maps, device inventory, rack planning and health checks.
- [Awesome Selfhosted](https://awesome-selfhosted.net/): application discovery.
- [r/homelab](https://www.reddit.com/r/homelab/): community inspiration.

These are references, not claims of deployment or authorship. Review upstream licences and security before adapting configurations; retain attribution where required.
