# OPTIPLEXLAB ACADEMY

The learning programme behind BLCKBX1. Deployment is not mastery.

## Curriculum

1. Git and GitHub
2. Computer hardware and operating systems
3. Linux fundamentals
4. Networking and subnetting
5. Linux administration and driver troubleshooting
6. Docker and Compose
7. Storage, backups and recovery
8. Infrastructure dashboards and monitoring
9. Programming, APIs and BYTE
10. Security foundations and hardening
11. Blue-team detection and incident response
12. Authorised red-team labs
13. Purple-team exercises
14. Proxmox and virtualisation
15. Kubernetes
16. Cloud, automation and GitOps
17. Embedded systems and BYTE MINI
18. Space tracking and receive-only SDR
19. Career preparation

## Learning method
One lesson at a time. Explain concepts and commands, predict outcomes, perform a small exercise, troubleshoot, verify and document. Use read-only checks first and backups before risky changes.

## Knowledge tracker
Statuses: not started, introduced, practising, understood, independently demonstrated, mastered. No mastery is claimed without evidence. Track exercises and evidence separately from deployment.

First practical: inspect Git history, rename the repository, update the local remote and make an independently understood commit.
