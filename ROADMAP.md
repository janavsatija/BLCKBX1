# Roadmap

One build at a time. Prioritise reliability and security before expanding the lab.

- [ ] Restic backups: identify data, establish 3-2-1 copies, test restoration
- [ ] SSH hardening: verify key access, enforce key-only login, evaluate MFA
- [ ] Confirm vulnerability remediation persistence and follow-up scan
- [ ] RAM upgrade / capacity assessment for heavier services
- [ ] Wazuh: deploy and connect one log source
- [ ] Verify isolated lab network
- [ ] Deploy Juice Shop or DVWA in the isolated environment
- [ ] Conduct authorised red-team exercise and collect blue-team telemetry
- [ ] Investigate, mitigate, retest and publish purple-team case study

## Documentation standard
For each build: objective, environment, problem, investigation, changes, verification, lessons, remaining work. Redact secrets and private information before publication.
